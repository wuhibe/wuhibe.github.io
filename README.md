# wuhibe.github.io

Source for my personal site, live at **https://wuhibe.github.io**.

Built with [Astro](https://astro.build/). Single-page portfolio — bold/technical aesthetic, light + dark themes, animated code-style project cards.

## Develop

```bash
pnpm install
pnpm run dev      # http://localhost:4321
pnpm run build    # outputs to ./dist
pnpm run preview
```

## Deploy

`main` → GitHub Actions → `gh-pages`. Configure once at **Settings → Pages → Source: gh-pages branch**.

## Stack

TypeScript · NestJS · Next.js · PostgreSQL · Docker
